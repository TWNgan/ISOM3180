# ISOM3180 Midterm 溫習站

**👉 網站（手機 / 電腦都得）：https://twngan.github.io/ISOM3180/**

HKUST **ISOM3180 Telecommunications and Computer Networking Management** midterm（Module 1–3）嘅個人溫習筆記同互動練習。
筆記用繁體中文（香港）寫，考試會用到嘅 keywords / 句子保留英文。

## 內容
| 部分 | 說明 |
|---|---|
| 🎯 考試攻略 | 範圍、形式、教授親口講嘅答題技巧、按出題比重排嘅溫習次序 |
| ⚡ Cheat Sheet | 考前 15 分鐘速讀版 |
| 📘📗📙📕 筆記 | M1 Exploring the Network · M2 Protocols & Communications · M3-I Devices & Switching · M3-II Collision & Broadcast Domains |
| ✍️ 官方 Review Questions | 28 題互動 MC（附詳細解釋），自動記錄錯題本 |
| 🧪 額外練習 | 66 題同風格練習題 + 隨機 25 題模擬測驗 |
| 🔢 Domain 計數訓練 | 數 collision / broadcast domains，一撳用顏色顯示答案；有隨機無限出圖 |
| 🔀 Switch 決策模擬 | MAC table learning + flood / forward / filter |
| 🖼️ Icon 辨認 · 🃏 Flashcards | 考試 diagram 冇名，只有 icon |

## 喺手機用
- 用 Safari / Chrome 開上面條 link → **「加至主畫面 / Add to Home Screen」**，之後好似 app 咁開，冇網都用得（offline cache）。
- 底部 tab bar：主頁 · 筆記 · 做題 · Domain · Cards；長頁面可以撳「📑 本頁目錄」跳段。
- 進度、錯題本、flashcards 進度儲喺手機 browser（localStorage）。
